## À propos

Je conçois et je livre des applications web complètes, du backend à la prod : SaaS métier, plateformes multi-tenant, sites e-commerce/vitrine sur-mesure. Stack principale TypeScript/Next.js côté front, Python ou Node côté back, Postgres, déployé et exploité par mes soins (VPS, Docker, monitoring).

Je code aussi avec des agents IA en usage réel — pas comme gadget, comme partie du workflow quotidien (revue de code, ops, automatisation de tâches répétitives).

## Actuellement

🔭 En veille perpétuelle sur les frameworks front modernes, les agents IA appliqués au dev, et l'architecture multi-tenant.
